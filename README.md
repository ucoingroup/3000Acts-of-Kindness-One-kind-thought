发心的“行善三千”若能落实到365天日常，便是将每日呼吸都化为修行。

以下将按时间、空间、人际关系、自然元素、特殊困境 等维度扩展至 365条，每一条皆可独立践行。您可每日任选几条随缘默念，一年圆满三千善念。

 【晨起·一日之计在于善】（1–30）

1. 醒来睁眼默念：愿一切众生从无明中醒来。
2. 伸懒腰时默念：愿众生舒展身心，去除昨夜沉滞。
3. 打哈欠时默念：愿众生消尽疲惫，得清新朝气。
4. 看窗外第一眼默念：愿此日所见皆美好，所遇皆善缘。
5. 起身下床默念：愿所有行动不便者得轻安步履。
6. 拉开窗帘默念：愿光照进一切幽暗角落。
7. 叠被子时默念：愿众生心安如平整床榻。
8. 穿拖鞋时默念：愿地府众生亦得柔软落脚处。
9. 洗脸时默念：愿众生洗去烦恼尘垢，面目清朗。
10. 刷牙时默念：愿众生口吐莲花，不出恶言。
11. 梳头时默念：愿众生理顺三千烦恼丝。
12. 照镜子时默念：愿众生见此面目本善，心生欢喜。
13. 上厕所时默念：愿众生排出病浊，通体轻安。
14. 冲水时默念：愿秽物流散，不染他人。
15. 洗手时默念：愿众生得清净手，做利他事。
16. 擦护手霜时默念：愿所有粗糙之手得滋润。
17. 穿衣服时默念：愿众生皆有蔽体御寒之衣。
18. 扣扣子时默念：愿众生心结皆得解开。
19. 拉拉链时默念：愿众生闭合是非之口。
20. 系鞋带时默念：愿众生步履稳健，不跌入坑。
21. 戴眼镜/隐形眼镜时默念：愿众生见真实，不迷幻相。
22. 喷香水/涂护肤品时默念：愿众生身心皆散发善香。
23. 称体重时默念：愿众生不为形役，心安即好。
24. 看天气预报时默念：愿风调雨顺，农人无忧。
25. 查手机消息时默念：愿所有信息传递善意而非焦虑。
26. 喝第一杯温水时默念：愿众生皆得甘露润喉。
27. 吃早餐前默念：愿饥者先得饱。
28. 咬第一口食物默念：愿此食化为能量，滋养利他之念。
29. 喝咖啡/茶时默念：愿众生清醒不迷，温和不躁。
30. 出门前回头看一眼家默念：愿家宅安宁，无人孤独。
